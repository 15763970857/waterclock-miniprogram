# 水时钟 · 微信小程序

一个只做一件事的喝水记录小程序：点一下记下喝了多少，用圆环和水位告诉你今天还差多少。

纯前端实现，没有服务端、没有云开发，所有数据只存在手机本地（`wx.setStorageSync`）。

## 功能

- **快速记录**：100 ml / 200 ml 两档一键记；也可以自定义水量（10~2000 ml，步进 ±10）
- **圆环进度**：Canvas 绘制的进度环 + 波浪水位，喝满 2000 ml 换色并提示达标
- **记录管理**：按时间倒序列出今日每一笔，支持撤回上一条、单条删除（带二次确认）
- **周报**：本周周一到周日的柱状图，标出 2000 ml 目标线，统计本周总量、日均和达标天数
- **时间点提醒**：可增删改 5 个默认提醒点（09:00 / 11:00 / 15:00 / 17:00 / 20:00）。小程序没有后台定时能力，所以采用「打开时补提醒」：进入小程序时检查今天已过、且尚未提醒过的时间点，只取最近一个弹窗提示一次，已提醒的点按日期记在本机，不会重复弹
- **本地存储**：数据按日期分桶存储，跨零点自动切换到新的一天；可离线使用

## 未实现 / 已知边界

- **订阅消息推送没有真正接入**。`utils/reminder.js` 里预留了 `SUBSCRIBE_TEMPLATE_ID` 常量和 `wx.requestSubscribeMessage` 的调用逻辑，但模板 ID 为空时整段跳过：设置页不渲染订阅入口，也不会发起请求。即使填了模板 ID，真正的手机通知也需要服务端在到点时调用微信的服务端接口下发，本项目没有服务端，所以只会走到「收集用户授权」为止。界面上的提醒仍是打开小程序时的本地弹窗。
- 数据只在本机：换设备、清除微信缓存后记录会丢失，没有导出 / 云同步。

## 运行方式

1. 安装并打开 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)
2. 选择「导入项目」，目录指向本仓库根目录（含 `app.json` 的那一层）
3. AppID 一栏：用自己的小程序 AppID，或直接选「测试号 / 游客模式」
4. 编译即可运行。项目零依赖，不需要 `npm install`、不需要构建

> 仓库里的 `project.config.json` 中 `appid` 已置为占位的 `touristappid`，导入时按第 3 步填写自己的即可。

## 技术栈

- 微信原生小程序（WXML / WXSS / JavaScript ES5 写法），基础库 3.5.5+
- Canvas 2D（`canvas type="2d"` + `requestAnimationFrame`）绘制进度环与水位动画
- `wx.setStorageSync` / `wx.getStorageSync` 本地持久化
- 无第三方库、无构建工具、无服务端

## 目录结构

```
.
├── app.js                      # 应用入口，仅设置全局目标 2000 ml
├── app.json                    # 页面注册、窗口样式、tabBar
├── app.wxss                    # 全局样式与设计变量
├── sitemap.json                # 索引规则
├── project.config.json         # 开发者工具项目配置（appid 为占位值）
├── images/                     # tabBar 图标与 logo
├── utils/
│   ├── store.js                # 数据层：按日期分桶的饮水记录、合计、增删
│   └── reminder.js             # 提醒数据层：提醒点配置、已提醒去重、订阅消息占位
└── pages/
    ├── today/                  # 今日：圆环 + 快捷记录 + 记录列表
    ├── weekly/                 # 周报：本周柱状图与统计
    └── reminder/               # 提醒：时间点增删改与开关
```
